# Storyboard first, then draw (2026-09-19)

## Why

A lecture (or a `#parts=N` drawcast) is N figures generated by N independent
runs of the single-figure pipeline, in parallel. Each part knows the others
only by their outline titles, so part 3 cannot bridge from what part 2
actually said or drew, notation drifts, and the per-part teaching pass
re-situates a topic the previous part already situated. One call writing
all N specs would cohere but leaves the quality envelope tuned for one
figure (long-output drift, all-or-nothing JSON, repairs per figure).

The split that keeps both: **the narration is written once, for the whole
series, then each figure is drawn to its lines** — screenwriter, then
animator.

## The pipeline

1. **Storyboard call** (replaces the outline call): the creative model at the
   author's effort, with the author's style profile, returns the same shape
   as the outline (title, parts with title/brief/level/chapter) plus, per
   part, `figure` (what is drawn, its named parts, what changes across the
   beats) and `script` (the spoken lines, in order, 8–14 per part). The
   teaching rules the per-part pedagogy pass used to check live in this
   prompt instead — situate once, bridge explicitly, one interesting thing
   per series, the aha in the last part, no signposting, notation fixed.
2. **Per-part draw**: the ordinary generateSpec, whose request now carries
   the part's figure and script with the instruction to STAGE the lines —
   each rides the draw command it belongs to, in order; lines may be
   tightened to fit the ink, never rewritten in content, reordered or added
   to. Repairs, lint, code checks, templates on demand: unchanged.
3. **No per-part teaching pass** for a part that has a script: its narration
   was authored for the series, and a pass that rewrites one part alone would
   undo the coherence the storyboard bought. (Also four Opus calls fewer per
   lecture.) A part without a script — the independent approach, or a
   partial lecture stored before this — keeps the pass.

## The choice

`Settings.approach`: `"storyboard"` (default) | `"independent"`. Picked in
the generation choices row beside Model and Effort; applies to `#parts=N`,
`#playlist` and every course run (the course panel reads the same setting).
A single figure has no parts and ignores it. The outline stored with a
partial lecture carries its scripts, so a resumed lecture draws its missing
parts to the same script.

## Later

Other approaches slot in beside these two: one call for the whole lecture,
sequential parts with memory. The picker and `GenerateConfig.approach` are
the seam.
