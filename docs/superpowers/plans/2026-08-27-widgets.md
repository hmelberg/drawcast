# Ask Widgets (click, piano, chess) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Three rounds, pushed separately, each with a bundled example.

**Goal:** `widget` on a check-mode ask swaps the answer device: `"click"` — click the element on the figure; `"piano"` — press a key on the drawn keyboard (it sounds); `"chess"` — click two squares for a move. The player is UNCHANGED in its judging: every widget gate resolves a string that `answersMatch` compares to `answer` — the payoff of the uniform gate contract.

**Shared architecture (round A builds it):**
- `AskArgs.widget?: "click" | "piano" | "chess"` (wire enum; requires `answer`; `retry` allowed).
- Plan: ask step carries `widget?` and, for click, `answerBox?` (bboxOf(answer) at plan time; warn when the id is unknown).
- Player ask case, auto path (`autoAnswers` or no gate) for widget asks: a laser-pointer demo at `answerBox` (reuse `pointerPath` + `effects.setPointer` — the laser is SVG, so it exports) instead of the typing card, then `typed = answer`. The export gate is bypassed for widget asks (the player runs the demo itself).
- Controls `askGateFor` dispatches on `step.widget`: the default text card, or a figure gate — a hint pill + Skip, clicks on the stage hit-tested against `elementBBoxes(hd.layout, makeBrowserMeasure())` mapped through the svg's LIVE viewBox (camera-proof) with the y-up flip; smallest containing box wins; a click marker colored right/wrong lingers; resolves the id/note/move string.
- Pure hit modules (node-tested): `src/ui/hit.ts` — `hitElement(boxes, p)`, `pianoKeyAt(keysBox, octaves, p)` (standard keyboard math from the keys-group bbox), `chessSquareAt(boardBox, p)`.

**Round A — click** (+ example "Find it on the figure": supply_demand, click the new equilibrium). Push.
**Round B — piano** (gate resolves the note name and SOUNDS it via `hd.timeline.tones.play([{notes}], tempo)`; intrinsic free play: while PAUSED, clicks that land on keys sound instead of resuming — pause-is-the-door). Example: "Press the C" on piano_keys. Push.
**Round C — chess** (two clicks → "e2e4"-style string; first click marks the source square). Example in the games pack (packs: ["games"]): a mate/best-move click. Push.

Docs each round: prompt bullet fragment, help, ROADMAP at the end.
