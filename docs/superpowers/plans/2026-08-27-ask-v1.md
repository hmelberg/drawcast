# Ask v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new `ask` command — a multiple-choice question posed mid-drawcast: in player mode the timeline pauses on pill buttons (skippable unless `required: true`), feedback is spoken; in movie mode it demonstrates (question spoken/captioned, beat, answer revealed) and never waits.

**Architecture:** `ask` is a new PlanStep whose *question* rides the existing narration channel (spoken + captioned — captions are painted into video exports), whose *choices* are DOM pill buttons from a `controls.ts` gate factory (input surface only — DOM is invisible in exports, which is correct: nobody can click a movie), and whose *feedback* is runtime speech through a new `Player.speakLine` helper. A new `Player.askGate` injectable mirrors `inputGate` exactly (controls assigns the interactive gate; the exporter assigns an auto-reveal beat; a bare player degrades to a timeout — never deadlocks). No spec elements, no layout changes.

**Tech Stack:** TypeScript, vitest (node env), no new dependencies.

**Spec:** `docs/superpowers/specs/2026-08-27-interactivity-principles.md` §3 (the one rule + `required` gates player mode only), §4 (exercise), §5 (adaptable element, demonstrate form = pose–beat–reveal).

## Global Constraints

- The verb list lives in 5 places — ALL must be updated: `schema.ts:424` ACTION_VERBS, `plan.ts:167` ACTION_KEYS, `lint.ts:155` ACTION_KEYS, `schema.ts:171` prose, `compiler-v1.md:27` + verb bullet.
- Wire schema stays flat: no oneOf/anyOf, `additionalProperties: false`, closed keys (the structured-output trap, schema.ts:1-7).
- `correct` is **1-based on the wire** (human/LLM-natural), **0-based in the plan step** (code-natural). Convert exactly once, in planCommands.
- Export TTS is pre-synthesized: every line `ask` can speak in a movie MUST be emitted by `collectSpeakLines` with byte-identical text and matching speaker/delivery/gender, or it is silent in exports.
- The movie never waits: the export askGate auto-reveals; `required` is read only by the interactive gate.
- Repo norms: `npx tsc && npm test` before each commit; `git log --oneline -2` right before each commit (parallel sessions); commit trailers (Co-Authored-By + Claude-Session).

```ts
  /**
   * Provider for the ask verb, set by the controls layer (choice buttons) or
   * the exporter (auto-reveal beat). Resolves the 0-based chosen index, or
   * null for skipped/auto. Must resolve on signal abort. When unset, ask
   * degrades to a short hold + reveal so a bare Player never deadlocks.
   */
  askGate: ((signal: AbortSignal, step: Extract<PlanStep, { kind: "ask" }>) => Promise<number | null>) | null = null;
```

Behavior of the case:
1. Gate first (buttons show while the question narration plays — runStep already started it).
2. `narrationBarrier()` after the gate so feedback never talks over the question.
3. correct → speak `right` if present, else nothing extra.
4. wrong (a number ≠ correct) → speak `wrong` if present, then speak the reveal line.
5. null (skipped/auto/no-gate) → speak the reveal line.
6. Reveal line = `right ?? choices[correct]`.
7. `speakLine(text, signal)`: narrated mode → `this.speech.speak(text, this.speedVal, signal, { gender: this.narratorGender ?? undefined })` + `setCaption(text)`; other modes → `setCaption(text)` + `waitScaled(Math.min(1400, SpeechManager.estimateMs(text) * 0.4), signal)` (mirror the existing silent-mode branch exactly — including the import of SpeechManager already present).

```ts
/** The ask verb's gate: choice pills over the stage; resolves the 0-based
 *  picked index, or null when skipped. Resolves on signal abort. */
export function askGateFor(stage: HTMLElement): NonNullable<Player["askGate"]> {
  return (signal, step) =>
    new Promise((resolve) => {
      const row = h("div", { class: "cs-askgate-row" });
      const gate = h("div", { class: "cs-askgate" }, row);
      let settled = false;
      const finish = (v: number | null, hold: number): void => {
        if (settled) return;
        settled = true;
        signal.removeEventListener("abort", onAbort);
        window.setTimeout(() => {
          gate.remove();
          resolve(v);
        }, hold);
      };
      const onAbort = (): void => {
        if (!settled) {
          settled = true;
          gate.remove();
          resolve(null);
        }
      };
      const pills: HTMLButtonElement[] = step.choices.map((choice, i) => {
        const pill = h("button", { class: "cs-askgate-pill" }, `${i + 1} · ${choice}`) as HTMLButtonElement;
        pill.addEventListener("click", (e) => {
          e.stopPropagation();
          if (settled) return;
          pill.classList.add(i === step.correct ? "right" : "wrong");
          pills[step.correct].classList.add("right");
          for (const p of pills) p.disabled = true;
          finish(i, 900);
        });
        return pill;
      });
      row.append(...pills);
      if (!step.required) {
        const skip = h("button", { class: "cs-askgate-pill skip" }, "Skip ▸");
        skip.addEventListener("click", (e) => {
          e.stopPropagation();
          finish(null, 0);
        });
        row.appendChild(skip);
      }
      gate.addEventListener("click", (e) => e.stopPropagation());
      signal.addEventListener("abort", onAbort);
      stage.appendChild(gate);
    });
}
```
