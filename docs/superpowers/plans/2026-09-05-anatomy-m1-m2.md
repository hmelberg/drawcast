# Anatomy M1+M2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An `anatomy` template that draws a named, colour-coded human body at three levels of detail from a data atlas, answers click-to-locate and multiple-choice questions on its parts, and can be given diseases to identify.

**Architecture:** Three separable units. An **atlas** (JSON data: named parts, closed rings, a part-of tree, nb/en/la names, a detail rank) built offline by a script from a public-domain SVG plus a parametric organ source. An **`anatomy` template** in its own pack that reads the atlas through a lazily-loaded `anatomy` engine — structurally a twin of `world_map`. And **polygon hit-testing**, the one code fix the click-asks need. Element ids ARE part ids, which is what makes `ask.widget: "click"` work with no new spec verbs.

**Tech Stack:** TypeScript, Vitest, Vite. No new runtime dependencies. The build script uses the house pattern for `.mjs` scripts that need TS modules (`createServer` from vite + `server.ssrLoadModule`, as in `scripts/sweep-round-examples.mjs:45-65`).

**Spec:** `docs/superpowers/specs/2026-09-05-anatomy-design.md`

## Global Constraints

- **Regions for v1, set by Hans 2026-09-05: skeleton and viscera.** No muscles, no nervous or vascular system. `systems` is a list so they can be added later without a shape change.
- **View:** `anterior` only. The `view` param exists and accepts only that value.
- **Atlas coordinate space:** `[1000, 2000]` (width, height), y-**down** in atlas units — the SVG source's own convention. The template flips to drawcast's y-up when it scales to the canvas. Every ring in every atlas file is in this space.
- **Point budgets, asserted by tests:** `atlas-body.json` ≤ 3 000 points; `atlas-skeleton.json` ≤ 6 000; `atlas-viscera.json` ≤ 6 000. The drawn scene is capped at **4 000 points** and drops detail rather than exceeding it.
- **Canvas:** `CANVAS = {w: 1000, h: 750}` (`src/layout/canvas.ts:6`).
- **Element ids are part ids** — `femur_left`, `liver`. Snake_case, English-derived, stable. They are the answers `ask.widget: "click"` compares against.
- **Anatomical names never go through the prose translation track.** Every id-shaped param carries `x-translate: false`. `tests/spec-i18n.test.ts` holds a drift guard that will demand this classification explicitly (it lists translatable paths per template and fails on any new string param).
- **Every manifest example must be lint-clean** — zero warn-level issues from `layoutSpec`, not just zero errors. The whole bundled library carries three warnings total; that is the bar.
- **Licence:** the v1 atlas derives from a public-domain source and ships MIT with the code. No CC BY-SA material enters this plan (that is M4, out of scope here).
- Run the full suite with `npx vitest run`. Typecheck with `npx tsc --noEmit`. Both must be clean before every commit.

```ts
// Pure hit-testing for the figure-answer widgets (logical y-up coordinates).
// DOM-free so node tests cover it; the gates map click events into logical
// space through the svg's live viewBox and call these.

import type { BBox } from "../layout/geometry";
import type { Pt } from "../layout/model";

/** Even-odd point-in-polygon on a closed ring (the last point joins the first). */
export function pointInRing(ring: readonly Pt[], p: Pt): boolean {
  let inside = false;
  for (let i = 0, j = ring.length - 1; i < ring.length; j = i++) {
    const [xi, yi] = ring[i];
    const [xj, yj] = ring[j];
    if (yi > p[1] !== yj > p[1] && p[0] < ((xj - xi) * (p[1] - yi)) / (yj - yi) + xi) inside = !inside;
  }
  return inside;
}

const areaOf = (b: BBox | undefined): number => (b ? b.w * b.h : Infinity);

/** The id of the element under the point, or null on a miss.
 *
 *  Elements that declare an OUTLINE (`rings`) are judged on that outline, not
 *  on their box — anatomy is the case that forces this: a liver's box swallows
 *  half a lung it does not touch, and the smallest-box rule then answers with
 *  whichever box happens to be smaller. Boxes remain the rule for everything
 *  that has no closed geometry (labels, axes, curves).
 *
 *  With slop > 0, a clean miss snaps to the nearest box within that many
 *  logical units — fat-finger tolerance for touch (and kinder mouse aim). The
 *  slop pass considers outlined shapes too, so a near miss on an organ is still
 *  rescued; only CONTAINMENT is outline-strict. */
export function hitElement(
  boxes: ReadonlyMap<string, BBox>,
  p: Pt,
  slop = 0,
  rings?: ReadonlyMap<string, Pt[][]>,
): string | null {
  let best: string | null = null;
  let bestArea = Infinity;

  // Pass 1: outlines. Smallest box among the shapes that actually contain p.
  if (rings) {
    for (const [id, rs] of rings) {
      if (!rs.some((r) => r.length >= 3 && pointInRing(r, p))) continue;
      const area = areaOf(boxes.get(id));
      if (area < bestArea) {
        bestArea = area;
        best = id;
      }
    }
    if (best !== null) return best;
  }

  // Pass 2: boxes, skipping anything that already answered "not me" in pass 1.
  for (const [id, b] of boxes) {
    if (rings?.has(id)) continue;
    if (p[0] < b.x || p[0] > b.x + b.w || p[1] < b.y || p[1] > b.y + b.h) continue;
    const area = b.w * b.h;
    if (area < bestArea) {
      bestArea = area;
      best = id;
    }
  }
  if (best !== null || slop <= 0) return best;

  // Pass 3: slop. Everything is eligible again — a near miss is a near miss.
  let bestDist = Infinity;
  for (const [id, b] of boxes) {
    const dx = Math.max(b.x - p[0], 0, p[0] - (b.x + b.w));
    const dy = Math.max(b.y - p[1], 0, p[1] - (b.y + b.h));
    const d = Math.hypot(dx, dy);
    if (d <= slop && (d < bestDist || (d === bestDist && b.w * b.h < bestArea))) {
      bestDist = d;
      bestArea = b.w * b.h;
      best = id;
    }
  }
  return best;
}
```

```ts
/**
 * Closed outlines per element id, the companion to elementBBoxes. Only closed
 * geometry contributes — an area, or a stroke drawn with `closed: true`. An id
 * with none is absent from the map, and hit-testing falls back to its box.
 */
export function elementRings(layout: Pick<LayoutResult, "drawables" | "order">): Map<string, Pt[][]> {
  const map = new Map<string, Pt[][]>();
  for (const id of layout.order) {
    const rings: Pt[][] = [];
    for (const d of leafDrawables(drawablesForId(layout.drawables, id))) {
      if (d.kind === "area" && d.pts.length >= 3) rings.push(d.pts);
      else if (d.kind === "stroke" && d.closed && d.pts.length >= 3) rings.push(d.pts);
    }
    if (rings.length > 0) map.set(id, rings);
  }
  return map;
}
```

```ts
// The anatomy atlas: named body parts as closed outlines in a shared
// coordinate space, with the part-of tree that drives detail levels and focus.

/** Atlas coordinates: x right, y DOWN, in a 1000 × 2000 box. The template
 *  flips y when it scales onto drawcast's y-up canvas. */
export type AtlasPt = [number, number];

export interface AtlasPart {
  /** Display names. `la` is the Latin (Terminologia) name; both are optional
   *  and fall back to `en`. These NEVER go through the prose translator. */
  name: { en: string; nb?: string; la?: string };
  system: "skeleton" | "viscera";
  /** Part-of parent id, or null for a root. Drives `focus` and detail rollup. */
  parent: string | null;
  /** Lowest `detail` level at which this part is drawn (1, 2 or 3). */
  detail: 1 | 2 | 3;
  sex: "any" | "female" | "male";
  /** Closed outlines. More than one for a part that reads as several pieces. */
  rings: AtlasPt[][];
  /** Optional cross-reference to an open anatomy ontology. */
  uberon?: string;
}

export interface Atlas {
  view: "anterior";
  /** [width, height] of the atlas coordinate box. */
  space: [number, number];
  source: string;
  parts: Record<string, AtlasPart>;
}

/** What a template's `layout` gets as `engines.anatomy`. */
export interface AnatomyEngine {
  /** Every part from the atlases needed for this request, already merged and
   *  filtered. Later atlases override earlier ones for the same id, so a
   *  detail-2 ring replaces the detail-1 stand-in of the same part. */
  parts(q: {
    systems: ("skeleton" | "viscera")[];
    detail: 1 | 2 | 3;
    sex: "neutral" | "female" | "male";
  }): Record<string, AtlasPart>;
  /** The atlas coordinate box, for scaling. */
  space(): [number, number];
}
```

Create `scripts/build-anatomy-atlas.mjs`:

```js
// Source art → atlas JSON. Deterministic, run by hand, output checked in:
//   node scripts/build-anatomy-atlas.mjs
//
// The skeleton comes from a public-domain Wikimedia SVG whose named <g> groups
// already carry the part-of tree (FootLeft ⊃ TarsalsLeft + MetatarsalsLeft +
// PhalangesFootLeft). The organs come from assets/anatomy-sources/viscera.mjs
// as parametric shapes, because the matching PD organ SVG is embedded raster.
//
// Raw, the skeleton is 131 633 points. Decimation is a precondition, not an
// optimisation, so every ring goes through Douglas–Peucker at a tolerance tied
// to the detail level it is being emitted for.

import { createServer } from "vite";
import { fileURLToPath } from "node:url";
import { readFileSync, writeFileSync, mkdirSync } from "node:fs";
import { VISCERA } from "../assets/anatomy-sources/viscera.mjs";
import { SKELETON_PARTS } from "../assets/anatomy-sources/skeleton-map.mjs";

const ROOT = fileURLToPath(new URL("..", import.meta.url));
const SRC = `${ROOT}assets/anatomy-sources/human-skeleton.svg`;
const OUT = `${ROOT}src/scenes/anatomy`;

/** Perpendicular-distance simplification. Keeps endpoints; closed rings keep shape. */
function simplify(pts, tol) {
  if (pts.length <= 3) return pts;
  const sqTol = tol * tol;
  const keep = new Uint8Array(pts.length);
  keep[0] = keep[pts.length - 1] = 1;
  const stack = [[0, pts.length - 1]];
  while (stack.length) {
    const [lo, hi] = stack.pop();
    let worst = 0;
    let idx = -1;
    const [ax, ay] = pts[lo];
    const [bx, by] = pts[hi];
    const dx = bx - ax;
    const dy = by - ay;
    const len = dx * dx + dy * dy;
    for (let i = lo + 1; i < hi; i++) {
      const [px, py] = pts[i];
      let t = len > 0 ? ((px - ax) * dx + (py - ay) * dy) / len : 0;
      t = Math.max(0, Math.min(1, t));
      const qx = ax + t * dx;
      const qy = ay + t * dy;
      const d = (px - qx) * (px - qx) + (py - qy) * (py - qy);
      if (d > worst) {
        worst = d;
        idx = i;
      }
    }
    if (worst > sqTol && idx > 0) {
      keep[idx] = 1;
      stack.push([lo, idx], [idx, hi]);
    }
  }
  return pts.filter((_, i) => keep[i]);
}

/** Shoelace area — rings smaller than this are noise from the source art. */
function ringArea(pts) {
  let a = 0;
  for (let i = 0, j = pts.length - 1; i < pts.length; j = i++) {
    a += (pts[j][0] + pts[i][0]) * (pts[j][1] - pts[i][1]);
  }
  return Math.abs(a / 2);
}

const round = (pts) => pts.map(([x, y]) => [Math.round(x * 10) / 10, Math.round(y * 10) / 10]);

/** The <g id="NAME"> … </g> block, found by depth-counting from its start tag. */
function groupBlock(svg, id) {
  const m = new RegExp(`<g\\b[^>]*\\bid="${id}"[^>]*>`).exec(svg);
  if (!m) return null;
  let i = m.index + m[0].length;
  let depth = 1;
  while (depth > 0) {
    const open = svg.indexOf("<g", i);
    const close = svg.indexOf("</g>", i);
    if (close < 0) return null;
    if (open >= 0 && open < close) { depth++; i = open + 2; }
    else { depth--; i = close + 4; }
  }
  return svg.slice(m.index, i);
}

const TOLERANCE = { 1: 6, 2: 3, 3: 1.5 };
const MIN_AREA = { 1: 400, 2: 120, 3: 30 };

async function main() {
  const server = await createServer({ root: ROOT, server: { middlewareMode: true }, appType: "custom", logLevel: "warn" });
  try {
    const { sampleSvgPath } = await server.ssrLoadModule("/src/scenes/svgpath.ts");
    const svg = readFileSync(SRC, "utf8");

    // The source's own viewBox → our 1000 × 2000 space.
    const vb = /viewBox="([\d.\-\s]+)"/.exec(svg);
    if (!vb) throw new Error("no viewBox on the source svg");
    const [vx, vy, vw, vh] = vb[1].trim().split(/\s+/).map(Number);
    const k = Math.min(1000 / vw, 2000 / vh);
    const ox = (1000 - vw * k) / 2;
    const oy = (2000 - vh * k) / 2;
    const toAtlas = ([x, y]) => [ox + (x - vx) * k, oy + (y - vy) * k];

    /** Rings for one named source group, decimated for one detail level. */
    const ringsFor = (groupId, detail) => {
      const blk = groupBlock(svg, groupId);
      if (!blk) throw new Error(`source group "${groupId}" not found`);
      const out = [];
      for (const pm of blk.matchAll(/\bd="([^"]+)"/g)) {
        for (const ring of sampleSvgPath(pm[1], detail === 3 ? 8 : 4)) {
          const mapped = ring.map(toAtlas);
          const simple = simplify(mapped, TOLERANCE[detail]);
          if (simple.length >= 3 && ringArea(simple) >= MIN_AREA[detail]) out.push(round(simple));
        }
      }
      return out;
    };

    const skeleton = {};
    const bodyLevel = {};
    for (const p of SKELETON_PARTS) {
      const full = { ...p.meta, system: "skeleton", rings: ringsFor(p.group, p.meta.detail) };
      delete full.group;
      skeleton[p.id] = full;
      if (p.meta.detail === 1) bodyLevel[p.id] = { ...p.meta, system: "skeleton", rings: ringsFor(p.group, 1) };
    }

    const viscera = {};
    const visceraLevel1 = {};
    for (const o of VISCERA) {
      const rings = [round(expandShape(o.shape))];
      viscera[o.id] = { name: o.name, system: "viscera", parent: o.parent, detail: o.detail, sex: o.sex ?? "any", rings, ...(o.uberon ? { uberon: o.uberon } : {}) };
      if (o.detail === 1) visceraLevel1[o.id] = viscera[o.id];
    }

    const stamp = (parts) => ({ view: "anterior", space: [1000, 2000], source: "Wikimedia Commons, Mikael Häggström, public domain; organs authored for drawcast", parts });
    mkdirSync(OUT, { recursive: true });
    const write = (name, obj) => {
      writeFileSync(`${OUT}/${name}`, `${JSON.stringify(obj, null, 1)}\n`);
      const n = Object.values(obj.parts).reduce((s, p) => s + p.rings.reduce((t, r) => t + r.length, 0), 0);
      console.log(`${name}: ${Object.keys(obj.parts).length} parts, ${n} points`);
    };
    write("atlas-body.json", stamp({ ...bodyLevel, ...visceraLevel1, body_outline: BODY_OUTLINE }));
    write("atlas-skeleton.json", stamp(skeleton));

/** Parametric shape → one closed ring, in atlas coordinates. */
export function expandShape(s) {
  const n = s.n ?? 48;
  const pts = [];
  for (let i = 0; i < n; i++) {
    const t = (i / n) * 2 * Math.PI;
    // Deterministic low-frequency wobble: organs are organic, never ellipses.
    const w = s.wobble ? 1 + s.wobble * Math.sin(3 * t + (s.seed ?? 0)) * Math.cos(2 * t + (s.seed ?? 0)) : 1;
    const x = Math.cos(t) * s.rx * w;
    const y = Math.sin(t) * s.ry * w;
    const a = ((s.rot ?? 0) * Math.PI) / 180;
    pts.push([s.c[0] + x * Math.cos(a) - y * Math.sin(a), s.c[1] + x * Math.sin(a) + y * Math.cos(a)]);
  }
  return pts;
}
```

```ts
async function loadAnatomy(): Promise<AnatomyEngine> {
  const [bodyMod, skeletonMod, visceraMod] = await Promise.all([
    import("./anatomy/atlas-body.json"),
    import("./anatomy/atlas-skeleton.json"),
    import("./anatomy/atlas-viscera.json"),
  ]);
  const body = bodyMod.default as unknown as Atlas;
  const detailed: Record<"skeleton" | "viscera", Atlas> = {
    skeleton: skeletonMod.default as unknown as Atlas,
    viscera: visceraMod.default as unknown as Atlas,
  };

  return {
    space: () => body.space,
    parts({ systems, detail, sex }) {
      const wanted = new Set(systems);
      const out: Record<string, AtlasPart> = {};
      const take = (id: string, p: AtlasPart) => {
        if (id !== "body_outline") {
          if (!wanted.has(p.system)) return;
          if (p.detail > detail) return;
          if (p.sex !== "any" && (sex === "neutral" || p.sex !== sex)) return;
        }
        out[id] = p;
      };
      // The body atlas first, then the detailed one for whichever systems were
      // asked for — so a fine ring replaces the coarse stand-in of the same id.
      for (const [id, p] of Object.entries(body.parts)) take(id, p as AtlasPart);
      for (const s of systems) {
        for (const [id, p] of Object.entries(detailed[s].parts)) take(id, p as AtlasPart);
      }
      return out;
    },
  };
}
```

```yaml
layout: |
  const C = kit.COLORS, MS = kit.SKETCH_MS;
  const eng = engines.anatomy;
  const [aw, ah] = eng.space();

  const sexIn = params.sex === "female" || params.sex === "male" ? params.sex : "neutral";
  const systems = Array.isArray(params.systems) && params.systems.length > 0
    ? params.systems.filter((s) => s === "skeleton" || s === "viscera")
    : ["viscera"];
  const detail = Math.min(3, Math.max(1, Math.round(typeof params.detail === "number" ? params.detail : 2)));
  const labelMode = params.labels === "all" || params.labels === "none" ? params.labels : "focus";
  const mono = params.color === "mono";
  const focusIn = Array.isArray(params.focus) ? params.focus : [];
  const highlightIn = Array.isArray(params.highlight) ? params.highlight : [];
  const markersIn = Array.isArray(params.markers) ? params.markers.slice(0, 8) : [];
  const findingsIn = Array.isArray(params.findings) ? params.findings.slice(0, 6) : [];

  // focus implies full detail for what is focused, so "zoom in" really shows more.
  const all = eng.parts({ systems: systems, detail: focusIn.length > 0 ? 3 : detail, sex: sexIn });

  // Names resolve case-insensitively against the id AND every language's name,
  // so both "liver" and "Lever" find the same part.
  const byName = {};
  for (const id of Object.keys(all)) {
    byName[id.toLowerCase()] = id;
    const n = all[id].name || {};
    for (const key of ["en", "nb", "la"]) if (n[key]) byName[String(n[key]).toLowerCase()] = id;
  }
  const missing = [];
  const resolve = (s) => {
    const hit = typeof s === "string" ? byName[s.trim().toLowerCase()] : undefined;
    if (!hit && typeof s === "string" && s.trim() !== "") missing.push(s);
    return hit;
  };
  const descendants = (root) => {
    const out = new Set([root]);
    let grew = true;
    while (grew) {
      grew = false;
      for (const id of Object.keys(all)) {
        if (!out.has(id) && all[id].parent && out.has(all[id].parent)) { out.add(id); grew = true; }
      }
    }
    return out;
  };

  const focusIds = new Set();
  for (const f of focusIn) { const id = resolve(f); if (id) for (const d of descendants(id)) focusIds.add(d); }
  const highlightIds = new Set();
  for (const hl of highlightIn) { const id = resolve(hl); if (id) highlightIds.add(id); }

  // What actually gets drawn: parts with geometry, minus anything focus excludes.
  let drawIds = Object.keys(all).filter((id) => all[id].rings.length > 0);
  if (focusIds.size > 0) drawIds = drawIds.filter((id) => focusIds.has(id) || id === "body_outline");

  // The drawn budget. Too dense a request loses a detail level rather than
  // sketching for ten seconds; the note says so out loud.
  const POINT_BUDGET = 4000;
  const countPts = (ids) => ids.reduce((s, id) => s + all[id].rings.reduce((t, r) => t + r.length, 0), 0);
  let reduced = false;
  for (let lvl = detail; lvl > 1 && countPts(drawIds) > POINT_BUDGET; lvl--) {
    drawIds = drawIds.filter((id) => focusIds.has(id) || id === "body_outline" || all[id].detail < lvl);
    reduced = true;
  }

  // Atlas space (y down) → canvas (y up), aspect preserved, cropped to focus.
  let bx0 = 0, by0 = 0, bx1 = aw, by1 = ah;
  if (focusIds.size > 0) {
    bx0 = Infinity; by0 = Infinity; bx1 = -Infinity; by1 = -Infinity;
    for (const id of drawIds) {
      if (id === "body_outline") continue;
      for (const r of all[id].rings) for (const [x, y] of r) {
        bx0 = Math.min(bx0, x); by0 = Math.min(by0, y); bx1 = Math.max(bx1, x); by1 = Math.max(by1, y);
      }
    }
    const mx = (bx1 - bx0) * 0.14 + 20, my = (by1 - by0) * 0.14 + 20;
    bx0 -= mx; bx1 += mx; by0 -= my; by1 += my;
  }
  const FRAME = { x0: 60, y0: 40, x1: 940, y1: 710 };
  const k = Math.min((FRAME.x1 - FRAME.x0) / (bx1 - bx0), (FRAME.y1 - FRAME.y0) / (by1 - by0));
  const cx = (FRAME.x0 + FRAME.x1) / 2, cy = (FRAME.y0 + FRAME.y1) / 2;
  const P = ([x, y]) => [cx + (x - (bx0 + bx1) / 2) * k, cy - (y - (by0 + by1) / 2) * k];

  const SYSTEM_COLOR = { skeleton: "#e6dcc4", viscera: C.demand };
  const PART_COLOR = {
    heart: C.demand, lung_left: "#c98f9b", lung_right: "#c98f9b", liver: "#8a5a3c",
    stomach: "#c9a15f", spleen: "#7d5a86", pancreas: "#c9b06a", brain: "#c9a3ae",
    kidney_left: "#8a5f4a", kidney_right: "#8a5f4a", small_intestine: "#d8a679",
    large_intestine: "#c08a5c", bladder: "#c9c47f", gallbladder: "#7f9a5c",
    thyroid: "#b07f8a", trachea: "#a8b0b8", diaphragm: "#b8877f",
    uterus: "#b07f95", prostate: "#a08a70",
  };
  const colorOf = (id) => mono ? C.ink : (PART_COLOR[id] || SYSTEM_COLOR[all[id].system] || C.ink);

  const drawables = [], labels = [], anchors = {}, order = [];
  const push = (d) => { drawables.push(d); order.push(d.id); };

  const centroidOf = (rings) => {
    let sx2 = 0, sy2 = 0, n = 0;
    for (const r of rings) for (const p of r) { sx2 += p[0]; sy2 += p[1]; n++; }
    return n > 0 ? [sx2 / n, sy2 / n] : [0, 0];
  };

  if (params.title) {
    const t = kit.text("title", [500, 720], params.title, { fontSize: 30 });
    push(t); anchors.title = [500, 720];
  }

  // The outline first: it is the ground everything else sits on.
  if (all.body_outline) {
    push(kit.stroke("body_outline", all.body_outline.rings[0].map(P), { closed: true, color: C.guide, strokeWidth: 3, ms: MS.stroke }));
    anchors.body_outline = P(centroidOf(all.body_outline.rings));
  }

  const drawn = drawIds.filter((id) => id !== "body_outline")
    .sort((a, b) => all[b].rings.reduce((s, r) => s + r.length, 0) - all[a].rings.reduce((s, r) => s + r.length, 0));

  for (const id of drawn) {
    const part = all[id];
    const base = colorOf(id);
    const lit = highlightIds.has(id);
    const children = part.rings.map((ring, i) => kit.area(id + "__" + i, ring.map(P), base, { opacity: lit ? 0.85 : 0.5, strokeWidth: 2.2, ms: MS.region }));

    else push(kit.group(id, children));
    anchors[id] = P(centroidOf(part.rings));
  }

  const nameOf = (id) => {
    const n = all[id].name || {};
    return n[lang] || n.en || id;
  };
  const wantLabel = (id) => labelMode === "all" || (labelMode === "focus" && (focusIds.has(id) || highlightIds.has(id)));

    order.push("label_" + id);

  markersIn.forEach((m, i) => {
    const id = resolve(m && m.part);
    if (!id || !anchors[id]) return;
    const at = anchors[id];
    push(kit.stroke("marker_" + i, [at], { shapeHint: { type: "circle", c: at, r: 7 }, strokeWidth: 3, fill: C.ink, ms: MS.dot }));

    labels.push(kit.label("marker_label_" + i, at, "above-right", text, { color: C.ink, fontSize: 20 }));
    order.push("marker_label_" + i);
  });

  const notes = [];
  if (missing.length > 0) notes.push("Unknown: " + missing.join(", "));
  if (reduced) notes.push("Detail reduced to fit");
  if (notes.length > 0) {
    push(kit.text("missing_note", [70, 60], notes.join(" · "), { fontSize: 18, color: C.guide, anchor: "start" }));
    anchors.missing_note = [70, 60];
  }

  return { drawables, labels, anchors, order };
```

```js
    if (!anchors[id]) continue;
    const f = findingFor[id];
    const rings = ringsFor(id);
    const c = centroidOf(rings);
    let box = { x0: Infinity, y0: Infinity, x1: -Infinity, y1: -Infinity };
    for (const r of rings) for (const [x, y] of r) {
      box = { x0: Math.min(box.x0, x), y0: Math.min(box.y0, y), x1: Math.max(box.x1, x), y1: Math.max(box.y1, y) };

    const sev = f.severity === "severe" ? 1.4 : f.severity === "mild" ? 0.7 : 1;
    const mark = C.regionLoss;
    if (f.condition === "fracture") {
      // A jagged break across the short axis of the bone.
      const across = w < h;
      const n = 7, seg = [];
      for (let i = 0; i <= n; i++) {
        const t = i / n;
        const jag = (i % 2 === 0 ? -1 : 1) * (across ? w : h) * 0.16 * sev;

      const r = Math.min(w, h) * 0.26 * sev;
```

**Spec coverage.** Every M1 and M2 section maps to a task: atlas format → 2, build script → 2, budgets → 3, engine → 4, template and params → 5, zoom/focus → 5+6, names and language → 5+8, polygon hit-testing → 1, the asks → 8, pathology → 7, lint-clean examples → 9. M3 (sound) and M4 (3D) are explicitly out of scope and are recorded in the roadmap by Task 10. The spec's "which 18 organs" open question is answered by Task 5's `viscera.mjs`.

**Type consistency.** `AtlasPart`/`Atlas`/`AnatomyEngine` are defined once in Task 2 and consumed unchanged in Tasks 3, 4 and 5. `hitElement`'s new 4th parameter and `elementRings`'s return type match between Task 1's implementation and Task 8's use. `findingFor`, `ringsFor` and `centroidOf` are defined in Task 5/7 and used only there.

**Known soft spots, flagged rather than hidden:**

1. **`lang` inside a pack layout is unverified.** Task 5 Step 6 says what to do if it is not in scope: fall back to `n.en` and open a follow-up. Do not invent plumbing.
2. **The organ coordinates are a first draft.** They were placed against the skeleton's landmarks by eye, not traced. Expect Hans to want them moved; that is what `viscera.mjs` is for, and moving one is a two-number edit plus a rebuild.
3. **Task 9 is the one with real uncertainty.** Label collision in a narrow body is a genuine layout problem, and "make it lint-clean" may take several iterations. It is deliberately the last task, so nothing else is blocked by it.
4. **Decimation quality is unproven by tests.** No test can assert "the femur still looks like a femur". Hans must look at a rendered figure before the atlas is called done — say so when handing the work back.
5. **Registering the pack and shipping an example are one act, not two.** `tests/examples.test.ts` fails the moment a ready template has no bundled example, which is why Task 5 carries the first one. The three that show off focus, findings and animated detail are Task 9.
6. **`draw` takes an array of ids.** `"draw": "all"` appears nowhere in `src/examples.json` and the schema rejects it. Every example in this plan names its ids.
