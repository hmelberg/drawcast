# Round Two Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give documents one home (disk, GitHub, Drive) for both Open and Save, delete the two controls that ask unwanted questions (the YAML/JSON picker and `↻ Re-render`), and give drawcast a palette with edges, a dark mode, and a mark it draws itself.

**Architecture:** Eight independent tasks. The palette work is CSS plus one pure `contrastRatio` helper that pins the ratios so they cannot regress. The re-render work replaces a button with `ensureRendered()`, whose one hazard is that re-rendering destroys the session owning the Play button. The GitHub source save is a new *caller* of the already-exported `commitFiles`, with a `sources/index.json` manifest so Open needs one read instead of a directory walk. The mark is generated once by a script using roughjs's headless generator and committed as a static SVG.

**Tech Stack:** TypeScript, Vite, vitest (`environment: "node"` — no DOM), roughjs (already a dependency), the existing `src/publish/github.ts` helpers.

**Spec:** `docs/superpowers/specs/2026-08-31-round-two-design.md`

## Global Constraints

- **No DOM in tests.** `h("div", {})` throws `document is not defined`. Only pure functions are unit-testable; a module-scope `h(...)` crashes on import. CSS is verified by asserting on source text, the pattern in `tests/shell-css.test.ts`.
- **Verify every CSS selector matches something that exists.** Four dead selectors were caught in the previous round. A rule that matches nothing looks finished and does nothing. Grep the class before writing its rule.
- **Watch a new assertion fail before committing it.** Three defects reached implementers in the previous round because a test covered the new thing and not the thing it replaced.
- **The figure keeps its paper ground.** `figure-style.ts` hardcodes `#fffefb`. Dark mode must not reach the drawing, and the figure's styles must stop reading chrome tokens (spec §5.3).
- **Behaviour is preserved** unless the spec names the change. The named changes are: Share loses its Spec file destination, `↻ Re-render` becomes automatic, and the editor stops showing JSON.
- Run `npm test` (155 files / 2598 tests at the start) and `npx tsc --noEmit` before every commit.
- Do not `git push`; the controller pushes.
- Do not use browser tooling — two agents stalled on it last round.

// tests/contrast.ts — WCAG relative luminance and contrast ratio.
export function contrastRatio(a: string, b: string): number {
  const lum = (hex: string): number => {
    const h = hex.replace("#", "");
    const ch = [0, 2, 4].map((i) => parseInt(h.slice(i, i + 2), 16) / 255);
    const lin = ch.map((c) => (c <= 0.03928 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4));
    return 0.2126 * lin[0] + 0.7152 * lin[1] + 0.0722 * lin[2];
  };
  const [x, y] = [lum(a), lum(b)].sort((p, q) => q - p);
  return (x + 0.05) / (y + 0.05);
}
```

// src/render/policy.ts
/**
 * Whether the editor's text is ahead of what was last drawn. A plain string
 * comparison on purpose: trimming would call a re-indent "no change", and in
 * YAML indentation IS the structure.
 */
export function needsRender(current: string, lastRendered: string | null): boolean {
  return lastRendered === null || current !== lastRendered;
}

// src/publish/source.ts
// Saving the SOURCE to GitHub — the .yaml you are editing, not the rendered
// page Share publishes for an audience. Both can exist for one document, and
// neither implies the other.

import { joinPath } from "../course/publish";
import { slugify } from "./github";

export interface SourceEntry { path: string; title: string; ts: string }
export interface SourceManifest { sources: SourceEntry[] }

export function sourcePathFor(title: string, dir: string, existing: string | null): string {
  // A document keeps the path it was first saved to. Retitling must not leave
  // the old file behind as an orphan nobody will ever delete.
  if (existing) return existing;
  return joinPath(dir, "sources", `${slugify(title) || "drawcast"}.yaml`);
}

export function sourceManifest(m: SourceManifest, e: SourceEntry): SourceManifest {
  const rest = m.sources.filter((s) => s.path !== e.path);
  const at = m.sources.findIndex((s) => s.path === e.path);
  return { sources: at === -1 ? [...rest, e] : m.sources.map((s) => (s.path === e.path ? e : s)) };
}
```
