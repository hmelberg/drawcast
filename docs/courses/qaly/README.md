# The QALY course (source)

Five lectures made locally with the drawcast skill, 2026-09-28/29: what a
QALY is, how it is calculated, the theory under it, the ethical debate, and
the empirical/technical debate. Each lecture ends on its end page (links to
the previous and next lecture).

- `course.md` — the course document (the course panel's format), with each
  lecture's status line and file.
- `NN-*.cast` — the built lectures, as script (no recorded narration yet; `.yaml` until 2026-10-03).
- `lecture-NN/` — the working files: `storyboard.json` (the narration) and
  `part-N.json` (each part's spec), for revising with `scripts/cast.mjs`.

Open it in the app (dev server running):
`http://localhost:5199/?course=/docs/courses/qaly/course.md` — then publish
from the course panel to put it on GitHub with narration.
